# 热处理合炉 V0.7.x Smoke Tests

## 执行原则
- 每次替换 `app.js / main.css / furnace.html` 后先跑 smoke tests，再继续开发。
- 每个测试文件单独导入，避免上一个用例残留影响结果。
- 先看 Console 是否有编译错误，再看业务逻辑。

## 最小必测路径
1. 打开 `furnace.html`，确认 Console 无红色编译错误。
2. 进入「工件详情」，清空任务，导入一个测试用例 Excel。
3. 点击「数据校验」，确认全部/有效/待确认/异常数量合理。
4. 进入「合炉设计」，点击「自动合炉分组」。
5. 选择质量/交付/成本任一策略，点击「推荐工装」。
6. 确认默认只出现当前策略 1 张推荐卡。
7. 点击「比较三种策略」，确认出现 3 张策略卡；再次切回单策略。
8. 点击「采用此方案」后进入「装载工装」，确认本次工装组合展示正确。
9. 点击「采用并生成」或「生成方案」，确认 3D 有结果或明确未装原因。
10. 进入「方案分析」，确认工艺匹配、工装推荐、方案对比卡片不冒充真实历史数据。
11. 点击「打印方案」，确认 PDF 弹窗仍正常。
12. 进入编辑摆放，移动一个工件，保存/退出，确认 3D 与分析数据没有明显不同步。

## 回归优先级
P0：Console 编译错误、导入失败、无法生成方案、PDF 弹窗失效。
P1：策略按钮语义错误、高度/搁板字段缺失、真实/示例数据提示错误。
P2：文案、样式、卡片拥挤、分数不理想。
